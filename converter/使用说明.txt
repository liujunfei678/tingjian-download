听见 · M4A 批量转 MP3
Windows 10 / 11，64 位 · 便携版 · 无需安装

【开始使用】
1. 若使用 ZIP 包，先解压整个文件夹。
2. 双击「听见批量转换.exe」。ffmpeg.exe 必须留在同一个文件夹。
3. 点击「添加文件」多选 M4A，或点击「添加文件夹」。也可以直接拖入文件或文件夹。
4. 选择保存位置和码率（默认 320 kbps），点击「开始转换」。
5. 完成后点击「打开输出文件夹」。可以双击列表中的已完成文件播放。

【文件处理】
- 原始 M4A 文件会完整保留。
- 所有成品集中保存到选择的输出文件夹，不保留子文件夹结构。
- 已有同名 MP3 会保留，新文件自动编号，例如「歌曲 (1).mp3」。
- 中文文件名、空格和特殊字符可用；同一原文件不会重复加入队列。
- 「包含子文件夹」影响添加或拖入文件夹时的扫描范围。
- 标题、歌手、专辑等常见文字标签尽量保留。封面不导出。
- 输出为 MP3、44.1 kHz、立体声。支持 AAC 和 ALAC 编码的普通 M4A。

【停止、失败和结果】
- 点击「停止」会结束当前转换，保留已完成文件，清理当前临时文件。
- 再次开始会跳过已完成项，转换等待、已停止和失败项。
- 单个文件损坏时会显示失败并继续处理其他文件。
- 双击失败项可以查看详细原因；「导出结果」保存中文 CSV 表格。
- 关闭窗口会停止任务并清理临时文件。队列只保存在当前会话内。

【音质】
M4A 转 MP3 通常涉及有损重编码。提高输出码率不会恢复源文件中已损失的音质。
128 kbps 文件较小；192 kbps 适合日常听音乐；256 / 320 kbps 尽量保留音质。
不支持 DRM 加密文件。

【离线与依赖】
不需要账号，不上传音频，不请求网络，不需要安装 Python 或 Node.js。
界面使用 Windows 的 .NET Framework 4.5+；Windows 10 / 11 通常已内置兼容版本。
本包附带 64 位 FFmpeg 独立程序，仅通过进程调用进行音频转换。
FFmpeg 版本、构建配置和源码地址见 third-party 文件夹，许可证见同目录 LICENSE-FFmpeg.txt。
转换器界面与处理源码附在 source 文件夹。
