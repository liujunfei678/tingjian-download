# 听见 2.0 侧栏视觉与交互验证

设计依据：用户已确认的 `docs/superpowers/specs/2026-10-18-tingjian-workbench-design.md`。在开始编写产品代码前，使用内置 ImageGen 生成完整资源、格式转换、设置三个界面的同一设计系统概念。用户已要求直接开发，因此未增加一次概念确认等待。

## 概念与设计系统

- 概念：`tingjian-v2-concept.png`，原始大小 1536×1024。
- 实现：现有原生 JavaScript / CSS 扩展界面，复用 `extension/icons/icon48.png` 波形标识。
- 颜色：米白底 `#f7f6f0`，墨绿文字 / 主按钮 `#173f35`，浅鼠尾草选中态 `#e8eee4`，边框 `#dedfd5`，暖白行背景 `#fffefa`。
- 字体：Segoe UI / Microsoft YaHei UI / Microsoft YaHei。品牌 25px、标题 25px、分组与文件名 13px、内容与控制 11–13px。320px 窄侧栏做对应缩减。
- 容器：纵向原生侧栏；紧凑品牌、下划线标签导航、可滚动内容、固定主操作底栏。无固定 440×600 限制。
- 组件：轻底色分组行、文件列表、细进度条、细边框文件夹选择、统一按钮与表单；无需生成任何生产图片资产。
- 动画：只对分组展开箭头做 150ms 过渡，并尊重减少动态效果偏好。

生成提示词要点：完整的三个 420×820 中文音频侧栏截图，资源包含当前网页、搜索、分组、选择、下载与底栏；转换包含文件/文件夹、包含子目录、码率、输出目录、队列进度与停止；设置包含两种保存位置、本地组件连接与配置说明、转换偏好及浏览器记录。指定上述精确颜色、波形品牌、可由 HTML/CSS 实现的列表结构，不使用营销标题、装饰图片、图表、卡片网格或浏览器外壳。内置工具输出已保存在本目录概念图。

首屏文案检查：资源 / 格式转换 / 设置、网页里的声音、播放音频，听见会自动收集。、已识别 / 未识别、转成 MP3、原文件保留，转换在本机完成。、按你的方式保存均保持概念及已批准设计方向。资源数量、文件名、目录、主机连接状态和任务状态来自实时数据，无虚构示例数据写入生产界面。

必要的实现差异：每个资源组增加“本组全选”；未识别行标注“名称待确认”；设置默认显示真实未连接状态，并提供展开的首次配置说明；M4A 行增加“下载并转 MP3”；窄侧栏允许列表纵向滚动而保留底栏；任务结果以可关闭的短暂提示显示。它们落实已批准的功能要求，使用同一色彩与字号系统。概念中的样例数据不会作为产品默认内容。

视觉修正：提高文件名、描述和控制字号；删除重复的每行来源文字，保留来源为链接提示，未识别说明仍显示；避免已提交待运行任务的“开始转换”误启用。没有剩余的重要视觉偏差。实现已按已批准设计方向与完整概念进行忠实核对。

## 自动交互验证

测试先于新面板代码编写，首次运行因入口尚不存在而失败；实现后通过 10 组情景，浏览器无脚本异常。测试命令：

```powershell
npm install
npx playwright install chromium
node tests/panel.browser.mjs
node --check extension/panel/panel.js
```

覆盖：名称来源分组与独立网络确认；搜索后的分组数量与按组选择；每标签页选择恢复；切换后旧响应失效；忽略其他窗口活动事件；普通下载、仅 M4A 的下载并转换；缺组件回退；需要时自动重连已配置组件；连接、目录、保存偏好及码率；文件夹递归添加；进度、停止、重试、打开与定位；已提交等待任务不可重复启动；新下载状态不被旧的已完成记录覆盖；失败重试；320×560 / 620×900 的三入口与固定底栏；关闭 API 不受支持时的明确引导；初次缓存读取期间切换标签页不被旧查询覆盖；本地重连期间切换标签页不改变原下载请求的标签页归属。

独立审查发现的初次标签页绑定竞态已修复，并用延迟 250ms 的缓存读取及真实激活事件加入回归；自动重连时的下载上下文同样在等待前固定，测试用延迟 200ms 的重连及标签页切换验证。

这些测试在真实 Chromium 渲染页面中模拟 Chrome API，以稳定覆盖异步竞态和原生对话框结果。实际侧栏宿主、真实 Native Messaging 与 FFmpeg 由主流程的扩展 / 主机集成验证另行记录，不能由本测试冒称已验证。
